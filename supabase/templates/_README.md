# قوالب إيميلات المصادقة

Supabase بيبعت إيميلات التأكيد واسترجاع كلمة السر بقوالب إنجليزية افتراضية —
سطر واحد بخط أزرق، مفيهوش اسم بيما ولا كلمة عربي واحدة. أول إيميل يوصل لأي حد
بيسجّل، فده أول انطباع عن المنصة.

الملفات هنا بتستبدلها بقوالب عربية RTL بهوية بيما.

## الملفات

| الملف | إمتى بيتبعت |
|---|---|
| `confirm-signup.html` | حد سجّل حساب جديد ولازم يأكد إيميله |
| `reset-password.html` | حد ضغط «نسيت كلمة السر» |
| `magic-link.html` | دخول بلينك بدون كلمة سر |
| `email-change.html` | حد غيّر إيميله — بيتبعت للعنوانين |
| `reauthentication.html` | تأكيد الهوية قبل عملية حساسة (كود ٦ أرقام) |

## المتغيرات اللي Supabase بيحطها

- `{{ .ConfirmationURL }}` — اللينك اللي بيكمّل العملية
- `{{ .Token }}` — كود ٦ أرقام، بديل للّينك
- `{{ .Email }}` — إيميل المستخدم
- `{{ .SiteURL }}` — عنوان الموقع

## التطبيق

**محلياً** — متظبّط في `supabase/config.toml` تحت `[auth.email.template.*]`،
بيشتغل لوحده مع `supabase start`.

**على الإنتاج** — لوحة Supabase ← **Authentication ← Email Templates**. لكل
قالب، افتح الملف من هنا وانسخ محتواه في خانة الـMessage body، وحط الـsubject
اللي مكتوب في أول كل ملف كتعليق.

## ملاحظات على تصميم إيميلات HTML

عملاء الإيميل مش متصفحات: Gmail بيشيل `<style>` في الويب، وOutlook بيرندر
بمحرك Word. علشان كده كل حاجة هنا **جداول وinline styles** — مفيش flexbox ولا
grid ولا كلاسات. الشكل ده مقصود، مش إهمال.

الخط: مفيش خط خارجي (Gmail بيمنع `@import`)، فالقوالب بتعتمد على خطوط النظام
العربية — Tahoma وSegoe UI اللي موجودين في كل مكان.
